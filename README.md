# 🎨 ACAA Lite – AI Color Accessibility Analyzer

ACAA Lite to lekki analizator dostępności kolorów, który sprawdza:

- kontrast WCAG 2.1,
- symulację protanopii,
- symulację deuteranopii,
- pary kolorów z plików CSS lub podanych ręcznie.

To darmowa wersja narzędzia.  
Wersja PRO zawiera:
- tritanopię,
- achromatopsję,
- analizę screenshotów,
- raporty HTML/PDF,
- API,
- CI/CD,
- generowanie alternatywnych palet kolorów.
